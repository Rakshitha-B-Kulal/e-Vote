e-Vote is a secure and user-friendly mobile-based online voting system developed using Android Studio with Java and Firebase as the backend. It provides a seamless experience for users to participate in elections from their mobile devices.

- Users can register, log in, cast votes, and view real-time results.
- Administrators can manage elections, create candidates, and oversee the voting process.

By leveraging Firebase Authentication & Firestore, e-Vote ensures real-time data synchronization, secure user data handling, and a modernized voting experience.
